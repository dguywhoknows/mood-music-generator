What it does

Everything in one place

AI composition as JSON

Key, mode, tempo, 8-chord progression, 32-beat melody, drum style, timbres

Chord-symbol parser

Chord-symbol parser (maj7, m7b5, sus, add9, slash chords …) and scale/chord-tone quantizer

Algorithmic composer fallback

Roman-numeral progressions per mode, chord-tone-anchored random-walk melodies

Web Audio synth

ADSR voices, lowpass filtering, synthesized kick/snare/hats, generated reverb impulse, compressor

Lookahead scheduler

Lookahead scheduler (Chris Wilson pattern) with humanized timing and velocity

Canvas piano roll

Canvas piano roll with live playhead and chord highlighting

Tempo

Tempo, transpose, timbre, drums, reverb controls; AI variations; Standard MIDI File export (4 tracks)

Library page

Save pieces with their mood, rename inline, pin favorites, sort by newest / most played / tempo, mini piano-roll previews, JSON export and import

Chord lab page

Type any progression for Krumhansl–Schmuckler key detection with ranked candidates, roman-numeral analysis with harmonic function, cadence detection and borrowed-chord highlighting

Questions

Good to know

Is it free?

Yes. Every feature is free.

Where is my data stored?

What you create stays in this browser on this device. You can export a backup or delete everything from Settings.

Do I need an API key?

Not to try it: the app runs in demo mode with sample AI output. For live AI, connect a free Groq or OpenRouter key in Settings.

What can I type into the AI box?

Anything you would ask a helpful colleague who knows the app, such as: "Rainy café at midnight, slow and jazzy". It plans the steps, runs the app's own functions and tells you what it did. The Instructions tab saves preferences every AI feature follows.

Can I see the code?

Yes. It is open source under the MIT license on GitHub, with a public test suite.
